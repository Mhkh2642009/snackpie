Clone the repository and run locally:

Terminal 
# Clone the repository
git clone https://github.com/snackpie/snackpie.git
cd snackpie

# Run interactive mode
python3 snackpie.py

# Or run a .pie file
python3 interpreter.py

Requires Python 3.10 or higher.
