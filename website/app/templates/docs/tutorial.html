👩‍🍳 SnackPie Tutorial

Learn to code with SnackPie step by step!

1 Your First Recipe

Let's start with the simplest thing: making Chef SnackPie talk! In SnackPie, we use say to print text.

recipe.pie Click "Bake" to run! 
say "Hello, SnackPie!"
say 'Baking is fun!'
say "Welcome to the kitchen!"

This will output:

>>>Hello, SnackPie! >>>Baking is fun! >>>Welcome to the kitchen!

Your turn! Open the Playground and try saying your own message!

2 Storing Ingredients (Variables)

When you want to save a value, put it in a labeled jar using =!

recipe.pie 
chef_name = "Alex"
say chef_name

cookies = "12"
say cookies
>>>Alex >>>12

Secret Ingredients! Start the jar name with _ to make it a constant that can't be changed:

_secret_sauce = "Honey & Mustard"
say _secret_sauce

3 Kitchen Math

Chef SnackPie is super fast at counting cookies! Just type a math problem:

3 * 5
120 / 5
10 + 20
>>>15 >>>24.0 >>>30

4 Asking Questions

Need to get input from the user? Use ask!

name = ask "What is your name? "
say "Hello, " + name + "!"

5 Making Choices (If/Else)

To make decisions, use an if block, add extra tests with orif, write a backup with else, and finish with end!

recipe.pie 
cookies = "12"

if cookies == "12":
 say "Perfect batch!"
orif cookies > "12":
 say "Too many cookies!"
else:
 say "Need more cookies!"
end

Important: Add a single space before instructions inside the taste test, so Chef SnackPie knows they belong to that step!
