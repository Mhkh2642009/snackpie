SnackPie Tutorial

Learn core SnackPie ideas in order. Read step, run recipe, then change one ingredient.

1Your First Recipe

Use say to print text. Text can use double quotes or single quotes.

recipe.pie Run in Playground 
say "Hello, SnackPie!"
say 'Baking is fun!'
say "Welcome to the kitchen!"

Output:

>>>Hello, SnackPie! >>>Baking is fun! >>>Welcome to the kitchen!
Chef hint: Change one message, then run again. Small changes teach fast.

2Storing Ingredients

Variables store values. Think of them like labeled jars. Use = to fill jar.

recipe.pie
chef_name = "Alex"
say chef_name

cookies = "12"
say cookies

Constants start with _. They protect values from changes.

_secret_sauce = "Honey & Mustard"
say _secret_sauce

3Kitchen Math

SnackPie can calculate numbers with +, -, *, and /.

3 * 5
120 / 5
10 + 20
>>>15 >>>24.0 >>>30

4Asking Questions

Use ask when recipe needs user input.

name = ask "What is your name? "
say "Hello, " + name + "!"

5Making Choices

Use if, orif, else, and end to choose path.

recipe.pie
cookies = "12"

if cookies == "12":
 say "Perfect batch!"
orif cookies > "12":
 say "Too many cookies!"
else:
 say "Need more cookies!"
end
Rule: Add one space before instructions inside each choice block.
