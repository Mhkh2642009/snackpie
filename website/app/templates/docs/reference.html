Language Reference

Exact syntax and short examples. Use this page when you know what you need and want quick rules.

say

Print text or values to output.

say "Hello!"
say 'World'
say variable_name

ask

Read user input and store answer.

name = ask "What is your name? "

Variables

Store values in named jars with =.

name = "Alex"
age = "12"
score = 100

Constants

Prefix name with _ to protect value from reassignment.

_secret = "hidden"
_secret = "new"  # ERROR!

Math Operations

Use common arithmetic operators.

3 + 5    # Addition
10 - 3   # Subtraction
4 * 2    # Multiplication
10 / 2   # Division

Conditionals

Make decisions with if, optional orif, optional else, and closing end.

if score > 90:
 say "A+!"
orif score > 80:
 say "Great job!"
else:
 say "Keep trying!"
end
Comparison operators: ==, !=, >, <, >=, <=.
