📋 Language Reference

Complete guide to SnackPie syntax.

say

Print text or values to the screen.

say "Hello!"
say 'World'
say variable_name

ask

Get input from the user.

name = ask "What is your name? "

Variables

Store values in labeled jars using =.

name = "Alex"
age = "12"
score = 100

Constants

Protect values with _ prefix. Cannot be changed!

_secret = "hidden"
_secret = "new"  # ERROR!

Math Operations

Perform calculations.

3 + 5    # Addition
10 - 3   # Subtraction
4 * 2    # Multiplication
10 / 2   # Division

Conditionals (if/orif/else)

Make decisions in your code.

if score > 90:
 say "A+!"
orif score > 80:
 say "Great job!"
else:
 say "Keep trying!"
end

Comparison operators:

  • == - Equal to
  • != - Not equal to
  • > - Greater than
  • < - Less than
  • >= - Greater than or equal
  • <= - Less than or equal
