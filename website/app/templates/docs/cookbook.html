Grade Checker

Check score and print matching grade.

if score >= 90:
 say "A - Excellent!"
orif score >= 80:
 say "B - Great!"
orif score >= 70:
 say "C - Good"
orif score >= 60:
 say "D - Passing"
else:
 say "F - Keep trying!"
end
